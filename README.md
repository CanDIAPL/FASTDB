# FASTDB

Fast Access to Survey Transients Database (FASTDB).

**Documentation:** https://fastdb.readthedocs.io

## Getting Started

There are two ways to run FASTDB locally:

| Path | Use when | Guide |
|------|----------|-------|
| **Docker Compose** | Local development, running tests, editing code | [docs/developers.rst](docs/developers.rst) |
| **Kubernetes (Helm)** | K8s deployment, multi-node testing, production-like environments | [helm/HELM_HOWTO.md](helm/HELM_HOWTO.md) |

Once you have a running environment, see [scripts/README.md](scripts/README.md) for
database seeding, demos, and benchmarks.
